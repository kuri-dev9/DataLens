# 주문 지표 사전

> 열거 장. 표 1행이 카드 1장이 된다. `card_key`로 지정한 `지표` 컬럼이 카드 제목이 되고,
> 그 컬럼이 없는 표는 카드로 만들지 않는다 — 아래 "수록 현황"이 그 예다.

## 수록 현황

`지표` 컬럼이 없으므로 이 표는 카드가 되지 않는다. 사람이 보는 메타 정보다.

| 구분 | 건수 |
| --- | --- |
| 매출 지표 | 4 |
| 고객 지표 | 3 |

## 매출 지표

| 지표 | 산식 | 단위 | 주의 |
| --- | --- | --- | --- |
| `net_revenue` | `SUM(amount) WHERE status='PAID'` | 원 | 취소 제외 (01장 §1) |
| `gross_amount` | `SUM(amount)` | 원 | 취소 포함. 매출이 아니다 |
| `refund_amount` | `SUM(amount) WHERE status='REFUNDED'` | 원 | 원주문 날짜 기준 (01장 §2) |
| `discount_total` | `SUM(discount_amount)` | 원 | NULL은 적재 누락 (01장 §3) |

## 고객 지표

| 지표 | 산식 | 단위 | 주의 |
| --- | --- | --- | --- |
| `buyer_count` | `COUNT(DISTINCT customer_id) WHERE status='PAID'` | 명 | 취소만 한 고객은 제외된다 |
| `repeat_rate` | `100.0 * 재구매자 / NULLIF(buyer_count, 0)` | % | 분모가 0이면 NULL |
| `customer_age` 🔒 | — | 세 | 민감 항목. 색인에서 제외된다 |

## 주문 상태 코드

절 제목이 맥락으로 붙는다 — 아래 `PAID`는 "주문 상태 코드의 PAID"로 색인된다.
행만 보면 무엇의 코드인지 알 수 없다.

| 지표 | 뜻 | 매출 포함 |
| --- | --- | --- |
| `PAID` | 결제 완료 | 포함 |
| `CANCELLED` | 결제 전 취소 | 제외 |
| `REFUNDED` | 결제 후 환불 | 차감 |
| `PENDING` | 결제 대기 | 제외 |
